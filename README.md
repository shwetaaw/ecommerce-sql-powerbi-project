# E-commerce Sales & Customer Analytics Dashboard

## Project Overview
This project analyzes e-commerce customer behavior, revenue trends, and product performance using PostgreSQL and Power BI.

## Tools Used
- PostgreSQL
- Power BI
- SQL

## Key Insights
- Average orders per customer is ~1.03 indicating low customer retention.
- Majority of customers are one-time buyers.
- Revenue is concentrated among a few key product categories.

## Features
- Revenue trend analysis
- Top customer analysis
- Product category analysis
- Customer behavior analysis
- Interactive dashboard with slicers


## Skills Demonstrated
- SQL Joins
- Aggregations
- Data Analysis
- Data Visualization
- Business Insights
- Power BI Dashboarding
